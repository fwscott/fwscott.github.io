Home Automation Privacy Policy

Last updated October 29, 2026

This policy covers the private "Home Assistant" Google OAuth application operated by Scotty Scott (fwscott.com). The application exists only to let a self-hosted Home Assistant server control the Google Nest thermostats in homes that Scotty Scott owns or manages. It is not offered to the public.

What data is accessed

With your permission, through Google's Smart Device Management API, the application reads thermostat information (names, temperature, humidity, mode, Eco status and setpoints) and changes thermostat settings. It also receives device update messages through Google Cloud Pub/Sub. It does not access email, contacts, files or any other Google account data.

How data is used

Thermostat data is used only to display and automate heating and cooling in the homes you authorized, for example switching to Eco mode between guest stays. Data is stored on a private Home Assistant server that is not reachable from the public internet.

Sharing

Data is not sold, shared with third parties, or used for advertising or analytics. It is processed only by Google (as the device provider) and the private Home Assistant server.

Retention and deletion

Thermostat history is kept on the Home Assistant server for its normal recording period and can be deleted at any time. You can revoke the application's access whenever you like in the Google Home app or at Google Nest partner connections.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
